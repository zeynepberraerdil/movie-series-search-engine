#  Movie & TV Series Search Engine

A modern, responsive, and interactive web application designed to search, filter, and explore detailed insights for movies and TV series. Built with vanilla JavaScript, modern CSS Grid/Flexbox layouts, and accessible modal architecture.

---

##  Features

- **Dynamic Search & Real-Time Filtering:** Instant content search with keyword matching and dynamic category tags (Genre & Media Type).
- **Interactive Detail Modal:** Rich pop-up modal displaying high-resolution posters, IMDb ratings, release year, runtime, plot summary, director, and full cast lists.
- **Empty State & Result Counter:** Real-time feedback showing total matched titles and friendly fallback prompts when no results match.
- **Cinematic UI/UX:** Dark-mode aesthetic with golden accents, smooth hover transitions, and Google Fonts (`Inter` & `Outfit`).
- **Fully Responsive & Accessible:** Fluid layout across mobile, tablet, and desktop viewports with ARIA accessibility roles and semantic HTML5.

---

##  Built With

- **HTML5:** Semantic architecture, accessible dialog modals (`role="dialog"`), and SVG icons.
- **CSS3:** Custom CSS variables, responsive Grid/Flexbox layout, overlay backdrops, and animations.
- **JavaScript (ES6):** Dynamic DOM rendering, event listeners, and array filtering algorithms.
- **Git & GitHub Pages:** SCM workflow and cloud deployment.
